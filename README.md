# LangChain-ChatBot
Using Langchain and OpenAI to careet a chatbot
## Steps to run the code:
- create .env text file and put all the api_keys
    - LANGCHAIN_API_KEY (https://docs.smith.langchain.com/administration/how_to_guides/organization_management/create_account_api_key#api-keys)
    - OPENAI_API_KEY (https://openai.com/api/)
    - LANGCHAIN_PROJECT="Langchain_chatbot"
- Create a file requirements.txt and put following library names and run pip install -r requirements.txt
    - openai
    - langchain
    - streamlit
    - langsmith
    - python-dotenv
- To run using streamlit
  - streamlit run app.py
